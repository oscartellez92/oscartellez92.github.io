01Featured / Agency revenue operations

Revenue OS.

Billing built around client performance.

A marketing agency I worked for bills clients on performance, with different terms for each client. Standard billing systems couldn't handle that model, so I built Revenue OS.

It pulls performance data from Klaviyo, applies each client's billing terms, and generates invoices, performance reports, and email drafts ready to send.

Softphone data brings sales activity into the same workspace. Sellers can track their commissions, which also depend on each client's performance.

Ozzie, the built-in AI assistant, can answer questions using operational and financial data, help troubleshoot errors, and generate invoices.

What it changes

Client results become the basis for billing and commission tracking, with reports and draft emails prepared in the same app.

  • Full-stack application
  • Klaviyo · Gmail · Adversus
  • Performance-based billing

02Personal project / Webshop pilots

growth-metrics.
Investigate missing conversions.

As a paid ads manager, I faced gaps in Google Ads and Meta conversion reporting. That experience was one reason I built growth-metrics with my own server-side tracking to compare captured conversion data with platform reports.

It's my personal project, currently being piloted with a few webshops. The app brings server-side measurement, order revenue, and Google Ads, Meta, and Klaviyo reporting into one workspace. Data-quality checks help make gaps visible.

Early pilot observation: in these webshops, Google Ads has consistently reported roughly half the return on ad spend (ROAS) shown by my server-side data.

  • Server-side tracking
  • Google Ads · Meta
  • Klaviyo
  • Data quality

03Applied AI / Sales-call knowledge

Find the detail.
Skip the replay.

Preparing a follow-up shouldn't mean replaying an entire sales call. I built a system that fetches softphone recordings, transcribes them locally (no API costs) with Whisper, separates speakers, and creates summaries using Gemma 4.

I connected a Hermes agent to the transcription database so teams can ask questions about past calls through Telegram. I developed the system locally and deployed it on a separate remote PC.

What it enables: retrieve call details and follow-up context by asking a question.

  • Local transcription
  • Hermes agent
  • Telegram

04API engineering / Growth Horizon

Opening Klaviyo
to more webshops.

Missing connectors kept some webshops out of reach for the agency's Klaviyo services. I built connectors for Lightspeed, Mijnwebwinkel, and Logic4 that weren't available at the time.

The connectors import customer history and synchronize new events and store activity with Klaviyo, enabling those stores to run email marketing workflows.

What it changed: the agency could offer Klaviyo to more stores, expanding the potential client base for both the agency and Klaviyo.

05Data engineering / Sales prospecting

40,000+ sites.
Research that shaped the offer.

I built multi-source scraping and enrichment workflows to find e-commerce prospects that fit the agency's target customer profile. Covering 40,000+ European e-commerce sites, the system checked for e-commerce activity and identified each store's platform (CMS), email marketing tools, and relevant contact information.

CMS data helped prioritize stores that connected easily to Klaviyo. Knowing which email marketing tool a store used also helped cold callers prepare before reaching out.

Being able to identify stores on platforms without a native Klaviyo connector helped the agency target its custom integration offering. Lightspeed was one example at the time.

What it changed: one dataset guided prospect selection, outreach segmentation, and a custom integration offering that differentiated the agency.

  • Python
  • Node.js
  • Data enrichment
